# Roboto Web Fonts

- Family: Roboto
- Weights: 400 and 700
- Subset: Latin
- Upstream: Google Fonts, Roboto v51
- Retrieved: 2026-08-28
- License: SIL Open Font License 1.1; see `OFL.txt`

Google Fonts currently serves both requested weights from the same variable-font
WOFF2 asset. The asset is stored under weight-specific filenames so consumers
retain a stable 400/700 contract if the upstream packaging changes later.
